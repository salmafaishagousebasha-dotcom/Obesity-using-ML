# Obesity-using-ML
 Project Overview
This project focuses on analyzing obesity-related data and predicting obesity levels using Machine Learning algorithms.

The project explores different factors such as age, gender, height, weight, eating habits, physical activity, and lifestyle choices to understand their relationship with obesity levels.

Objectives
- Analyze obesity-related data.
- Perform data cleaning and preprocessing.
- Identify and handle missing values and duplicate records.
- Detect and handle outliers using the IQR method.
- Perform Exploratory Data Analysis (EDA).
- Visualize patterns and relationships in the dataset.
- Build and compare Machine Learning classification models.

Dataset
**Dataset Name:** Obesity Dataset

The dataset contains information about:
- Gender
- Age
- Height
- Weight
- Family history with overweight
- Food consumption habits
- Water consumption
- Physical activity
- Transportation habits
- Obesity level

**Target Variable:** `NObeyesdad`

 How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

**Step 2:** Install the required libraries.

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

**Step 3:** Make sure `ObesityDataSet.csv` is available in the project folder.

**Step 4:** Open the Jupyter Notebook.

```bash
jupyter notebook
```

**Step 5:** Open `ObesityModel.ipynb` and run all the cells.
